# The map picture (`map.webp`)

`map.webp` is Grand Theft Auto V's own map of Los Santos and Blaine County. It is Rockstar Games' and Take-Two
Interactive's, not es_mdt's: es_mdt's MIT licence does not cover it and gives you no rights to it. It is here only to be
used with GTA V on FiveM, where Rockstar's terms for the platform apply (https://fivem.net/terms), the same way WHIP's
own map pack (`whip_media_map`) ships GTA's map. es_mdt is not affiliated with, endorsed or sponsored by Rockstar Games
or Take-Two Interactive.

Don't want it in your copy? Delete `map.webp`: the Live map then draws a plain grid with every unit and call on it. Or
use your own picture of the same layout (4096 x 4096 px): put it in this folder, or on any https:// address, and set
`Config.LiveMap.image` in `mdt/config.lua` (for example `'img/mymap.webp'`).
